# AWS Cloud File Sharing System

Serverless file management system built using AWS services.

## Architecture

User
 ↓
API Gateway
 ↓
Lambda
 ↓
S3 + DynamoDB

## Features

- File upload
- Metadata storage
- Secure access
- Download links
- Serverless architecture

## Tech Stack

- AWS S3
- AWS Lambda
- API Gateway
- DynamoDB
- Python

## Future Improvements

- Authentication
- Notifications
- Expiring links
- File versioning
