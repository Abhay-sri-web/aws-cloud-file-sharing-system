# Requirements Analysis

## Project Name
AWS Cloud File Sharing System

## Objective
Develop a serverless cloud-based file sharing application that allows users to upload, manage, and securely download files using AWS services.

---

## Functional Requirements

### FR-1
Users can upload files.

### FR-2
Files are stored in Amazon S3.

### FR-3
File metadata is stored in DynamoDB.

### FR-4
Users can download files using secure pre-signed URLs.

### FR-5
Users can list uploaded files.

### FR-6
Users can delete uploaded files.

---

## Non-Functional Requirements

- High availability
- Scalability
- Low latency
- Secure file access
- Serverless architecture
- Cost efficient

---

## AWS Services

- Amazon S3
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- AWS IAM
- Amazon CloudWatch
